# 30-Day Daily Android App Factory Slate

**Core Rule:** Build one genuinely useful, non-slop native Kotlin + Jetpack Compose Android app every day via **Google AI Studio (Build -> Android)**, powered by real hardware sensors, deterministic DSP/math, and clean tactical UI — zero thin AI wrappers.

- **Online-Enhanced + Offline-Resilient (Days 3–30):** Every future app includes live online data/sync (using free, keyless public REST APIs, webhooks, or network services via `javax.net.ssl.HttpsURLConnection` + `kotlinx.coroutines.Dispatchers.IO` + `org.json`) backed by local `SharedPreferences` caching so it works seamlessly both online and off-grid.
- **Google Play Store Ready & Downloadable (Days 3–30):** Every future app uses a unique `io.github.elizabackrooms.<slug>` package ID (`targetSdk = 35`, `versionCode = 1`, `versionName = "1.0.0"`), includes graceful runtime permission rationale cards and an in-app **Field Guide & Privacy / Data Safety** disclosure tab, generates a `play_store_listing.md` release kit, and triggers **"Download app"** in Google AI Studio once compiled.
