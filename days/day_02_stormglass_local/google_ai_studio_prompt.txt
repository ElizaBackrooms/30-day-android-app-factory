### DUAL-MODE HARDWARE SENSOR HANDLING:
- On startup, detect `sensorManager.getDefaultSensor(Sensor.TYPE_PRESSURE)`.
- If available: Auto-bind `SensorEventListener` to sample real-time millibar/hPa data, low-pass filter the noise, and display a green "HARDWARE SENSOR: ACTIVE" badge.
- If unavailable (e.g., Moto G Stylus 4G variants): Gracefully switch to "MANUAL LOGGING MODE", showing an amber badge. Provide a tactile, 1-tap manual pressure entry bar (+/- 0.1 and +/- 1.0 hPa nudges plus direct entry) so users with wrist barometers or NOAA weather radios can input readings. The app, graphing, and Zambretti algorithms must work 100% identically.

### CORE DATA & LOGIC:
1. Data Model:
   `data class PressureReading(val timestamp: Long, val pressureHpa: Float, val isManual: Boolean = false, val note: String = "")`
   Persist readings locally in `SharedPreferences` via `org.json.JSONArray`, keeping up to 100 recent entries.
2. Zambretti Algorithm (Negretti & Zambra 1915):
   - MSLP: `mslp = stationPressure * (1.0f - elevationMeters / 44330.0f).pow(-5.255f)`.
   - 3-hour trend: `deltaP = currentPressure - pressure3HoursAgo`.
   - Classify trend: Falling (`deltaP <= -1.6f`), Steady (`-1.6f < deltaP < 1.6f`), Rising (`deltaP >= 1.6f`).
   - Compute Zambretti Index (1..26) with seasonal (+1 Summer / -1 Winter) and wind-quadrant modifiers, mapped to clear maritime/squall forecasts.
3. Squall Warning Engine:
   - Detect rapid drop (`deltaP <= threshold`, default `-2.0f` within 3 hours): trigger flashing crimson banner "SQUALL WARNING: RAPID PRESSURE DROP DETECTED" and an audible alert via `ToneGenerator(AudioManager.STREAM_ALARM, 80).startTone(ToneGenerator.TONE_CDMA_ALERT_CALL_GUARD, 400)`.
