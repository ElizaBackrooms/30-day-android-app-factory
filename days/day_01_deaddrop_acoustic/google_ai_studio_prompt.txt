DSP & PACKET ENGINE (PURE KOTLIN, ZERO-ALLOCATION HOT PATH):
Implement `ModemProtocol.kt` and `BfskCodec.kt`:
1. Constants:
   - Sample rate: `44100` Hz, 16-bit signed PCM mono
   - Baud rate: `300` baud -> `147` samples per bit (`SAMPLES_PER_BIT = 147`)
   - `FREQ_MARK = 1200.0` Hz (bit 1), `FREQ_SPACE = 2200.0` Hz (bit 0)
   - `SYNC_WORD = 0xAA55`
2. CRC-16-CCITT (`0x1021`, initial `0xFFFF`, no final XOR):
   - Computed over `[typeByte, lengthByte, ...payloadBytes]`.
3. Packet Frame (MSB-first bit serialization):
   - 4 bytes Preamble: `0x55, 0x55, 0x55, 0x55`
   - 2 bytes Sync Word: `0xAA, 0x55`
   - 1 byte Type: `0x01` (TEXT), `0x02` (SOS_LOC), `0x03` (PING)
   - 1 byte Payload Length (`1..120`)
   - N bytes UTF-8 payload (max 120 bytes)
   - 2 bytes CRC-16-CCITT (big-endian)
   - 1 byte Postamble: `0xFF`
4. Modulator (`encodeToPcm(packetBytes: ByteArray): ShortArray`):
   - Phase-continuous FSK (`phase += 2.0 * PI * freq / 44100.0`, wrapped at `2.0 * PI`) generating `147` samples per bit at ~80% peak amplitude (`26000`).
5. Demodulator (`BfskDemodulator` streaming sample consumer):
   - Use a pre-allocated circular `FloatArray(147)` window and `step = 21` samples (`7` sub-steps per bit, `147 / 21 = 7`).
   - Every 21 samples, run Goertzel over the 147-sample window for both `1200.0 Hz` and `2200.0 Hz` (`coeff = 2.0 * cos(2.0 * PI * f / 44100.0)`), computing normalized energy `markEnergy` and `spaceEnergy` and squelch-checked hard bit `if (markEnergy >= spaceEnergy) 1 else 0`.
   - Maintain 7 parallel shift registers (one per sub-step phase `0..6`), shifting each phase's bit every 7 steps.
   - Monitor all 7 registers for `0xAA55` (when signal energy exceeds a noise floor threshold). On sync match, lock onto that phase, read `type` and `length` (validate `length in 1..120`), read `length` payload bytes + `2` CRC bytes, verify CRC-16-CCITT, and invoke a callback with the decoded packet, computed CRC hex, `crcValid` boolean, and estimated SNR in dB.
6. Audio I/O:
   - TX: `AudioTrack` (`USAGE_MEDIA`, `CONTENT_TYPE_SONIFICATION`, `ENCODING_PCM_16BIT`, `CHANNEL_OUT_MONO`, `MODE_STATIC`) on `Dispatchers.IO`, releasing cleanly after playback completes.
   - RX: `AudioRecord` (`MediaRecorder.AudioSource.MIC`, `44100`, `CHANNEL_IN_MONO`, `ENCODING_PCM_16BIT`) on `Dispatchers.Default` reading into a single pre-allocated `ShortArray`, feeding `BfskDemodulator` and emitting UI telemetry (downsampled 48-bar waveform + mark/space levels) throttled to ~20 FPS to avoid recomposition churn.

TORCH MORSE BEACON (`TorchBeaconController.kt`):
- Implement full International Morse Code table (`A-Z`, `0-9`, space/slash).
- Timing from WPM (`dotMs = 1200L / wpm`, dash = `3 * dotMs`, intra-char gap = `dotMs`, char gap = `3 * dotMs`, word gap = `7 * dotMs`).
- Use `CameraManager` to find the first camera ID with `CameraCharacteristics.FLASH_INFO_AVAILABLE == true` and toggle `setTorchMode(id, state)` wrapped safely in `try/catch`.
- Always update `torchStateOn: Boolean` in UI state so an on-screen strobe indicator mirrors the Morse signal even on devices/emulators without a hardware flash. Ensure `finally` turns the torch OFF when stopped or when ViewModel clears.
